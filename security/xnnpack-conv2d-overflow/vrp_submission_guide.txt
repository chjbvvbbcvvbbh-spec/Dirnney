Finding 1 — GPU Process Heap Overflow
File:    gpu/command_buffer/service/gles2_cmd_decoder.cc:12629
Type:    uint32 integer overflow → heap-buffer-overflow in GPU process
Trigger: GL_TEXTURE_2D_ARRAY + GL_COMPRESSED_RGB8_ETC2 with depth ≥ 257
         (requires compromised renderer to bypass imageSize check)

Summary for VRP report:
  DecompressTextureData() computes:
    output_pixel_size * width * height * depth  (all uint32_t)
    = 4 * 2048 * 2048 * 257 = 4,311,744,512 > UINT32_MAX
    → wraps to 16,777,216 (16 MB) → HeapArray allocated at 16 MB
    → SW ETC2 decompressor writes 4.1 GB → heap overflow in GPU process

  Three independent verifications:
    1. Integer arithmetic confirmed in JS: u32(4*2048*2048*257) == 16777216
    2. ETC2 + TEXTURE_2D_ARRAY accepted (NO_ERROR confirmed in Chrome 150)
    3. Source code confirms no overflow check before HeapArray allocation

  Severity: HIGH — GPU process code execution (sandbox escape from renderer)
  VRP classification: Post-renderer-exploit privilege escalation
