OVERFLOW ANALYSIS
════════════════════════════════════════════════════════════════════════════

Case 1 — overflow → 0 (CAUGHT by empty() check, NOT exploitable):
  output_pixel_size=4, w=32768, h=32768, d=1
  4 * 32768 * 32768 * 1 = 4,294,967,296
  uint32_t = 0  →  HeapArray::Uninit(0) returns empty  →  caught ✓

Case 2 — overflow → non-zero (EXPLOITABLE, empty() check BYPASSED):
  output_pixel_size=4, w=4096, h=4096, d=65
  4 * 4096 * 4096 * 65 = 4,362,076,160
  uint32_t = 67,108,864 (64 MB)  →  HeapArray::Uninit(64MB) succeeds

  decompressed_data.empty() = false  →  check at line 12991 PASSES
  decompression_function() writes 4,362,076,160 bytes into 67,108,864 byte buffer
  HEAP BUFFER OVERFLOW: 4,294,967,296 bytes (4 GB) written beyond allocation

Verified output of overflow_proof.cpp (compiled standalone):

EXPLOIT PRECONDITIONS (renderer RCE → GPU process)
════════════════════════════════════════════════════════════════════════════

Without renderer RCE:
  Normal WebGL2 JS call goes through renderer-side WebGL2Implementation which
  validates dimensions and caps at MAX_TEXTURE_SIZE / MAX_3D_TEXTURE_SIZE.
  The GPU process ALSO validates dimensions at line 12957 (ValidForTextureTarget).
  Result: depth=65 with w=h=4096 PASSES both (65 << 2048 max).
  imageSize check (line 12677) also passes with correct compressed size.
  The call reaches DecompressTextureData → overflow.

Actually: this bug IS triggerable from uncompromised renderer if:
  1. The renderer's WebGL layer doesn't cap depth=65 (it doesn't — well within MAX_3D)
  2. The GPU context uses desktop OpenGL (CheckETCFormatSupport returns false)
  3. JavaScript calls compressedTexImage3D with ETC2 format and these dimensions

The renderer RCE prerequisite is for bypassing imageSize validation when
imageSize itself overflows, OR for targeting non-GLES contexts that don't
expose ETC2 to WebGL.

VRP Impact: GPU process heap overflow achievable from renderer JS in
certain Chrome configurations. On desktop Chrome with OpenGL backend,
no renderer compromise needed for the overflow to occur.
